# Análisis de logs

Este directorio contiene registros de práctica para aprender análisis defensivo de logs.

Aquí deben guardarse sólo logs sintéticos, de ejemplo o anonimizados. No subas registros reales que incluyan contraseñas, tokens, direcciones privadas, datos personales u otra información sensible.

## Archivos de práctica

- `practica-auth.log`: registro de autenticación SSH utilizado para practicar identificación de accesos aceptados, intentos fallidos, usuarios, direcciones IP, horarios y patrones repetidos.

## Objetivos de análisis

Las prácticas incluyen preguntas como:

- cuántos eventos aparecen;
- qué usuarios intervienen;
- qué accesos fueron aceptados o rechazados;
- qué direcciones IP se repiten;
- en qué horarios ocurren los eventos;
- qué conclusiones están respaldadas por el registro y cuáles serían solamente hipótesis.
