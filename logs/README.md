# Análisis de logs

Este directorio se usará más adelante para practicar análisis defensivo de registros.

Aquí deben guardarse sólo logs sintéticos, de ejemplo o anonimizados. No subas registros reales que incluyan contraseñas, tokens, direcciones privadas, datos personales u otra información sensible.

Al comenzar, practica responder preguntas simples: cuántos eventos hay, qué usuarios aparecen, qué errores se repiten y en qué horarios ocurren.
