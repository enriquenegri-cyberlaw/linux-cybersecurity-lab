# Bash

Bash es un intérprete de comandos que también permite crear scripts para automatizar tareas repetitivas.

Antes de escribir scripts, conviene dominar comandos básicos, rutas, permisos y códigos de salida.

Los primeros ejercicios pueden incluir variables, argumentos, condiciones y mensajes claros. Ejecuta scripts sólo en archivos y entornos propios o autorizados, y prueba primero con datos de ejemplo.
